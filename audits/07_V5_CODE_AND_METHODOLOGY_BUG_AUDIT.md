## 1. Purpose of This Audit

Following VLTHR Lab's falsification-first review standard (where agent-assisted and initial research code is treated as untrusted until audited line-by-line against raw data and mathematical specifications), we audited the `v5` rotating-machinery signal-physics and cross-rig validation pipeline (`v5_signal_physics.py`, `v5_learners_and_calibration.py`, and `run_apsens_v5_protocol.py`).

Seven concrete implementation and methodological defects (`BUG-V5-01` through `BUG-V5-07`) were identified, documented, patched, and re-verified in `RUN_20261121_115035_apsens_v5_patched_audit`.

## 2. Ledger of Uncovered Defects & Verified Patches

| Bug ID | Severity | Module & Location | Defect Description (What Was Wrong) | Verified Engineering Fix & Measured Impact |
| :--- | :---: | :--- | :--- | :--- |
| **`BUG-V5-01`** | **CRITICAL** | `run_apsens_v5_protocol.py` (`extract_or_load_nasa_ims_healthy_and_rtf`) | Because only pre-aggregated 9-feature NASA IMS summary tables existed on disk (rather than raw 20 kHz waveforms), the initial `v5.0` loader synthesized a sine + Gaussian noise waveform (`0.15*sin(...) + 0.45*N(0,1)`) for 12 IMS bearings inside `E3-Pool-Exp`, mixing synthetic waveforms into a `BENCHMARK_MEASURED` cohort. | Deleted the synthetic waveform generator completely (`QA Gate 1` asserts `synthetic_rows == 0`). Replaced with 100% real measured `25.6 kHz` 2-channel accelerometer waveforms from `XJTU-SY` (4 spaced early-run-in healthy snapshots and 4 late-fault snapshots across all 15 physical bearings = 120 real recordings), yielding **$n_0 = 87$ real measured healthy operating runs** (`HUST 15 + Ottawa 12 + XJTU 60`). |
| **`BUG-V5-02`** | **HIGH** | `v5_signal_physics.py` (`extract_csc_block`, lines 155-182) | When Computed Order Tracking (COT) angular resampling (`theta_revs`) was active on variable-speed recordings (`University of Ottawa`), the STFT carrier envelope matrix `S_env` was resampled onto uniform shaft revolutions (`theta_u`), **but the cyclic frequency axis `alphas` was still computed using time frequency `frame_fs = fs / hop` (Hz) instead of shaft orders (`cycles/rev`)**. | Computed cyclic order spacing `d_rev = total_revs / n_frames` whenever `using_angular_orders` is active, filtering cyclic shaft orders $\alpha \in [0.4, 35.0]$ orders/rev and re-extracting `Ottawa` features. |
| **`BUG-V5-03`** | **HIGH** | `run_apsens_v5_protocol.py` (`build_mafaulda_v5_multichannel`) | Initial `E2-MAFAULDA` grouped all 1,951 files by 5 speed bands (`MAF_SB0..4`). For fault files, that allowed the same physical fault severity (e.g., `imbalance/20g`) to appear at some speeds in `train` and other speeds in `test`. Conversely, grouping `normal` by contiguous speed bands held out the entire `50-60 Hz` top speed range in one fold. | Grouped all 1,902 MAFAULDA fault recordings by **`fault_class + "_" + condition_path`** (so all 49 shaft speeds of each held-out fault severity stay together in one fold) while interleaving the 49 normal speeds across the 5 folds. Result: `E2-MAFAULDA` achieved **`2.04%` FAR (`1/49`)**, **`100.0%` fault recall (`1,902/1,902`)**, and **`0.9997` ROC-AUC** (`P3`). |
| **`BUG-V5-04`** | **HIGH** | `run_apsens_v5_protocol.py` (`evaluate_pipeline_on_fold`) | `IntegrativeConformalGate` (Liang, Sesia & Sun, *JRSS-B* 2024) was implemented in `v5_learners_and_calibration.py` but never called inside `evaluate_pipeline_on_fold()`, and the fallback quantile expression `(n0_cal * (1 - alpha)) / n0_cal` algebraically canceled `n0_cal` instead of computing $\lceil (n_{0,\text{cal}}+1)(1-\alpha) \rceil / n_{0,\text{cal}}$. | Wired `IntegrativeConformalGate` directly into `evaluate_pipeline_on_fold()` alongside the exact finite-sample conformal order statistic and Dual-Track parallel features (`38` Track 1A CPW/COT/CSC/Autogram/TKEO + `15` Track 1B unwhitened Hilbert/spectral features). |
| **`BUG-V5-05`** | **MEDIUM** | `run_apsens_v5_protocol.py` (`extract_or_load_hust_v5`) | For `HUST` normal files (`N400, N402, N404`, etc.), `physical_bearing_id` used `file[:-4]` (`15` IDs), counting the 3 load conditions (`0 W, 200 W, 400 W`) of each physical bearing (`N4..N8`) as 3 distinct bearings. | Stripped the two trailing load digits so `HUST` healthy `physical_bearing_id` maps strictly to the `5` physical normal bearing specimens (`HUST_N4` through `HUST_N8`). |
| **`BUG-V5-06`** | **MEDIUM** | `v5_learners_and_calibration.py` (`WeibullOpenSetGate.fit`) | `WeibullOpenSetGate.fit()` hardcoded Weibull `shape = 2.5` on unwhitened Euclidean distances across 64 correlated features instead of fitting `scipy.stats.weibull_min.fit` on class-covariance-whitened Mahalanobis tail distances (causing `horizontal-misalignment` open-set AUROC to drop to `0.4940`). | Implemented Ledoit-Wolf class-covariance-whitened Mahalanobis distances + 2-parameter Weibull MLE (`scipy.stats.weibull_min.fit(tail_dists, floc=0.0)`). Result: `E7-OpenSet` novelty AUROC jumped from **`0.7045 -> 0.9235`** (`imbalance`) and from **`0.4940 -> 0.8570`** (`horizontal-misalignment`), clearing the `>= 0.85` gate on both! |
| **`BUG-V5-07`** | **MEDIUM** | `run_apsens_v5_protocol.py` (`evaluate_pipeline_on_fold`) | Inner 3-fold CV score buffers `s0_in` and `s1_in` were initialized with `np.zeros(...)`. If any inner fold was skipped, leftover `0.0` entries polluted the healthy calibration distribution and biased the conformal quantile downward. | Initialized inner-CV score buffers with `np.nan` and restricted Platt scaling and conformal calibration strictly to evaluated finite indices (`~np.isnan(s1_in)`). |
