# Digital Twin Simulation Evidence (Three-Twin Live Sample Packages)

**Evidence class: SIMULATED (not field data, not a live plant).**

Two synthetic sample packages from the VLTHR Lab three-twin digital twin simulation of the fictional facility FS-ZNA-01 (Zanara Synthetic Flow Station, Niger Delta onshore setting, modelled on ISO 14224:2016 / OREDA conventions). Each package covers 3,650 simulated days, seed 6001.

| File | Design capacity | Size |
| :--- | :--- | :--- |
| SAMPLE-THREE-TWIN-LIVE-4kbopd.zip | 4,000 bopd | ~18 MB |
| SAMPLE-THREE-TWIN-LIVE-25kbopd.zip | 25,000 bopd | ~45 MB |

## Contents of each zip
Three simulation arms, each with telemetry.csv, flow.csv, events.csv, decisions.csv, summary.csv and a hash-chained audit.csv:
- SIM_A_RTF: run-to-failure (no predictive intervention)
- SIM_B_TBM: time-based (calendar) maintenance
- SIM_C_HYB: hybrid, condition-based early warning
Plus package.json (package metadata, model notes) and .live3-state.json (simulator state).

## How to read these honestly
- All values are generated by a simulator. Per package.json, roughly 75% of failure modes carry an observable condition signature and the rest are invisible to the detector by design.
- Any failure-reduction figure from these packages is a simulation result awaiting field deployment. It must not be cited as a measured industrial outcome.
- Integrity: see public/MANIFEST.sha256 for the SHA-256 of each zip. Verify with: certutil -hashfile <zip> SHA256
